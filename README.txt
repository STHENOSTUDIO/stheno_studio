STHENO STUDIO - UPDATED OVERSIZED TEES

This version adds:
- Oversized Tees category
- CYBER RUSH and INVASION products
- Clean front/back product assets derived from the supplied product presentation image
- Arrow buttons to switch front/back
- Product modal with front/back arrows
- Basic custom T-shirt preview with image upload, size, sleeve, colour, front/back and image-size controls

To run:
1. Open this folder in VS Code.
2. Install Live Server if needed.
3. Right-click index.html -> Open with Live Server.

Note: The customizer preview is a front-end prototype. Before accepting real orders, connect it to a backend/order system and generate/save production-ready artwork.
